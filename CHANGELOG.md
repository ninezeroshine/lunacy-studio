# Изменения

Формат: новые версии сверху, раздел `## [X.Y.Z] — дата`. Текст раздела показывается в окне обновления.

## [1.0.4] — 2026-10-19

- Экспериментальная графика экрана: нарисованы экраны встроенного меню клавиатуры — «Настройки» (Fn + Ctrl + →, выбор Fn + Enter), эффекты, цвет подсветки, связь, громкость, язык, а также шкалы яркости (Fn + ↑ / ↓) и скорости (Fn + ← / →). Раньше там были тёмные экраны со служебными числами. Залейте набор графики ещё раз («Экран» → «Графика экрана»).

## [1.0.3] — 2026-10-18

- Экран выбора Win / Mac в наборе графики теперь по правильному адресу — он появляется при переключении режима. Залейте набор графики ещё раз («Экран» → «Графика экрана»).

## [1.0.2] — 2026-10-18

- Больше нет ложного предупреждения «Запись в клавиатуру оборвалась» во время обычной записи: оно показывается только при настоящем обрыве.
- Значки больше не растягиваются на весь экран, если для них не задан размер.
- Окно программы открывается по центру экрана, а не прилипшим к половине.
- Экспериментальная графика экрана: нарисован экран выбора Win / Mac (адрес оказался неверным, исправлено в 1.0.3).

## [1.0.1] — 2026-10-18

- В подсказке значка в трее видна версия программы.
- «Настройки» → «О программе»: точнее сказано, что хранится в папке данных и что обновление её не трогает.
- Файл контрольных сумм выпуска читается стандартными утилитами (`sha256sum -c`).

## [1.0.0] — 2026-10-18

Первый публичный выпуск.

- Обзор: живой пульт с загрузкой компьютера и темпом печати, статистика по всем разделам.
- Клавиши: переназначение в обычном и Fn-слое, выбор нажатием настоящей клавиши, готовые рецепты.
- Макросы: запись с клавиатуры и из текста, сцена проигрывания, назначение на клавишу, Fn + клавишу или сочетание вроде Ctrl + Shift + M.
- Подсветка: встроенные эффекты, свои цвета по клавишам, живые режимы.
- Экран: редактор видео, GIF и картинок, двенадцать анимированных узоров, рисунок поверх, «Мои видео».
- Сигналы: фокус-таймер, подсказчик горячих клавиш, Claude Code, тепловая карта.
- Профили, сброс к заводскому, автозапуск, автообновление с GitHub.
- Экспериментально (выключено по умолчанию): свой набор графики экрана и «Живые числа».
