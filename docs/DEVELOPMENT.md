# Как устроена Lunacy Studio

## Части

```
studio/                 сервис на Python (только стандартная библиотека) и интерфейс
  main.py               запуск: сервис, значок в трее, окно (Edge в режиме приложения)
  server.py             HTTP API на 127.0.0.1:47800; изменяющие запросы — с токеном X-Studio-Token
  device.py             DeviceManager: один замок на клавиатуру, переподключение
  live.py               живая подсветка (подсказки, раскладка, Claude Code, таймер, Ambilight, нагрузка)
  combos.py             макрос на сочетание клавиш: хук ловит сочетание, макрос печатается через SendInput
  library.py            «Мои видео»: готовые кадры для слота экрана
  graphics.py           набор графики экрана во флеш (экспериментально)
  livescreen.py         «Живые числа» на часах экрана статуса (экспериментально)
  updater.py, version.py  автообновление с GitHub Releases, номер версии
  store.py, profiles.py  настройка в %APPDATA%\LunacyStudio\profile.json и именованные профили
  data/keyboard.json    геометрия и коды клавиш
  assets/               фоны, иконка, набор графики экрана (pack.bin.gz)
  ui/                   интерфейс: ES-модули без сборки, js/pages — разделы, js/core — общее, css/
lunacy/                 протокол клавиатуры: HID на ctypes (hidwin.py), команды (proto.py), картинки, флеш
tests/                  проверки; большинство работает на заглушке клавиатуры (fake_kb.py)
tools/build_pack.py     сборка набора графики экрана (нужны Pillow и numpy, только для сборки)
packaging/              запускалка, иконка, установщик Inno Setup, build.py
```

Интерфейс общается только с сервисом. Сервис держит клавиатуру и всё, что должно работать без открытого окна: живую подсветку, сочетания макросов, сигналы.

## Запуск из исходников

Нужен Python 3.11+ для Windows.

```bash
pythonw -I studio/main.py            # без консоли; значок в трее
python -I studio/main.py --no-browser   # с консолью, без окна
```

Переменные окружения для проверок:

- `LUNACY_STUDIO_PORT=47806` — другой порт, чтобы поднять вторую копию рядом с рабочей;
- `LUNACY_NO_DEVICE=1` — не открывать клавиатуру вовсе (сборка, CI);
- `LUNACY_NO_UPDATE=1` — не ходить на GitHub за обновлениями.

## Тесты

Без клавиатуры, на заглушке:

```bash
python -I tests/t7_claude_hooks.py     # хуки Claude Code на временной копии настроек
python -I tests/t9_store.py            # хранение профиля: битый файл, резервная копия
python -I tests/t12_graphics.py        # графика экрана: статус, превью, запись, обрыв, отказы
python -I tests/t13_live_screen.py     # «Живые числа»: вход, выход, самовосстановление фона
python -I tests/t15_combos.py          # сочетания макросов: проверка входа, сверка, порядок событий
node tests/t8_ui_drafts.mjs            # черновики интерфейса: сдвиг номеров, запись, отмена
node tests/t14_screen_plan.mjs         # план кадров редактора экрана
```

С поднятой заглушкой сервиса:

```bash
python -I tests/stub_studio.py --port 47804 --block-delay 0.01   # в отдельном окне
set STUDIO_URL=http://127.0.0.1:47804
python -I tests/t5_studio_api.py       # сквозная проверка API
python -I tests/t16_library.py         # «Мои видео» и сочетания через API
```

`t5_studio_api.py` без `STUDIO_URL` идёт в рабочую Studio и меняет настоящую клавиатуру (в том числе сбрасывает её к заводской). Запускайте так только сознательно.

Заглушка ставит настоящий хук клавиатуры Windows, поэтому если в момент теста печатать, проверка сигнала Claude Code может сброситься — это ожидаемо, перезапустите.

## Протокол

Команды — HID-отчёты по 64 байта: `04 xx` с полезной нагрузкой. Раскладка — `04 10`/`04 26`, макросы — буфер 3 520 байт, подсветка — `04 12`/`04 20`, экран — `04 72` (слот GIF, до 69 кадров 240×135 RGB565) и `04 38` (графика во внешней SPI-флеш с адреса 0). Подробности в `lunacy/proto.py` и `lunacy/spiflash.py`.

## Сборка

```bash
python packaging/build.py
```

Нужны Inno Setup 6 и интернет при первой сборке (встраиваемый Python с python.org, сумма закреплена в `build.py`). Результат в `dist/`: установщик, портативный ZIP, `SHA256SUMS.txt`.
