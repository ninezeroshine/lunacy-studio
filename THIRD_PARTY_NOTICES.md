# Сторонние компоненты

Lunacy Studio распространяется по лицензии MIT (файл `LICENSE`). Внутри программы есть чужие компоненты, у каждого своя лицензия.

| Компонент | Где | Лицензия |
|---|---|---|
| Python 3.11 (встраиваемый дистрибутив с python.org) | `runtime/` в установленной программе | [PSF License](https://docs.python.org/3/license.html) |
| Шрифт Inter (Rasmus Andersson и авторы Inter) | `studio/ui/fonts/` | SIL Open Font License 1.1, текст в `studio/ui/fonts/OFL.txt` |
| anatomy kit (`iso-kit`) — изометрические рисунки | `studio/ui/vendor/anatomy/` | MIT, текст в `studio/ui/vendor/anatomy/LICENSE.txt` |
| Transitions.dev — переход при открытии страниц | `studio/ui/vendor/transitions/` | Лицензия Transitions.dev: использовать в своём продукте можно, публиковать как отдельную библиотеку переходов нельзя. Текст в `studio/ui/vendor/transitions/LICENSE.txt` |

## Торговые марки

Lunacy Studio — неофициальная программа. Она не связана с производителем клавиатуры Lunacy In Space, не одобрена и не поддерживается им. «Lunacy» и названия моделей — торговые марки их владельцев; здесь они названы только затем, чтобы было понятно, с какой клавиатурой работает программа.

Протокол клавиатуры восстановлен для совместимости, по наблюдению за обменом с клавиатурой. Файлов и картинок из программы производителя в репозитории нет: раскладка клавиш записана заново в собственном формате (`studio/data/keyboard.json`), графика экрана нарисована своим кодом (`tools/build_pack.py`).
